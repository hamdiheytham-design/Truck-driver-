DRIVER PRO V2.4 — مشروع Android
================================

هذه النسخة مبنية على V2.3 مع إضافة تتبع GPS حقيقي أثناء بقاء التطبيق مفتوحاً، مع المحافظة على مفتاح البيانات المحلي driverProData وتفضيلات المستخدم driverProPrefs. لا يتطلب التطبيق Firebase أو حساباً سحابياً.

الجديد في V2.4:
- طلب إذن الموقع من Android عند أول تشغيل لتتبع GPS.
- استخدام GPS_PROVIDER عند منح الموقع الدقيق، أو NETWORK_PROVIDER عند منح الموقع التقريبي فقط.
- بدء وإيقاف التتبع يدوياً من صفحة الرحلات.
- عرض المسافة المحسوبة من نقاط GPS ودقة آخر قراءة.
- حفظ مسافة جلسة GPS مؤقتاً محلياً حتى لا تضيع عند إعادة تحميل الواجهة.
- حفظ الرحلة بمسافة GPS عند ترك عدادي الانطلاق والوصول فارغين، أو استخدام عداد المركبة بالطريقة القديمة.
- تخزين مصدر المسافة ونقطتي البداية والنهاية للرحلة المسجلة عبر GPS.
- تعديل الرحلات المحسوبة عبر GPS دون تحويلها خطأً إلى سجلات عداد يدوي.
- المحافظة على السجلات القديمة والوظائف السابقة.

طريقة الاستخدام:
1. افتح صفحة الرحلات واختر المركبة.
2. اضغط بدء تتبع GPS وامنح التطبيق إذن الموقع وشغّل خدمة الموقع في الهاتف.
3. انتظر ظهور إشارة GPS. يجب أن تكون دقة القراءة 50 متراً أو أفضل حتى تدخل في حساب المسافة.
4. اضغط إيقاف التتبع عند نهاية الرحلة.
5. أدخل نقطة الانطلاق والوجهة والطرود والمدخول. اترك عدادي الانطلاق والوصول فارغين ليُعتمد GPS، أو أدخل العدادين معاً لاستخدام طريقة العداد اليدوي.
6. احفظ الرحلة.

قيود مهمة:
- التتبع يعمل فقط أثناء بقاء التطبيق في الواجهة. يتوقف تلقائياً عند انتقال التطبيق إلى الخلفية لتجنب تتبع خفي أو استهلاك البطارية؛ أعد تشغيله يدوياً عند العودة.
- المسافة تقديرية وتتأثر بجودة إشارة الأقمار الصناعية، المباني، الأنفاق والطقس. قارنها بعداد المركبة، ولا تعتمد عليها وحدها في الفوترة أو القياسات القانونية.
- لا يوجد تتبع مستمر بعد إغلاق التطبيق أو عند إطفاء الهاتف.
- لا يوجد اتصال بحاسوب الشاحنة أو OBD-II أو CAN Bus. مؤشرات الحرارة والوقود وضغط الهواء في V2.3/V2.4 تبقى يدوية.
- GPS لا يحتاج إلى الإنترنت عند استخدام إشارة الأقمار الصناعية، لكن تحديد الموقع عبر الشبكة قد يستفيد من اتصال الإنترنت.

البيانات:
- تبقى البيانات الأساسية في localStorage تحت المفتاح driverProData دون تغيير.
- تحفظ مسافة جلسة GPS المؤقتة تحت driverProGpsDraft.
- لا يحذف تحديث V2.4 أي سجلات قديمة.

الاختبار والبناء:
- تم فحص JavaScript باستخدام Node.js وسلامة أرشيف ZIP.
- لم يتم بناء APK أو اختبار طلب الأذونات أو استقبال GPS على هاتف Android فعلي في هذه البيئة.
- افتح المشروع في Android Studio، نفّذ Gradle Sync ثم Build APK. اختبر على هاتف حقيقي مع تفعيل الموقع ومنح إذن الموقع الدقيق.


تحديث V2.5 — خريطة الرحلات والمسارات:
- إضافة صفحة خريطة مستقلة داخل التطبيق.
- عرض المسار الحالي أثناء التتبع، وعرض المسارات المحفوظة مع الرحلات.
- حفظ نقاط GPS المقبولة داخل سجل الرحلة محلياً، مع حد أعلى لتقليل استهلاك مساحة التخزين.
- إضافة إذن INTERNET لتحميل خرائط OpenStreetMap وLeaflet.
- نقاط GPS تسجل محلياً، لكن خلفية الخريطة تحتاج اتصال إنترنت؛ لا توجد خرائط بلا اتصال في هذه النسخة.
- لا يعمل تتبع GPS في الخلفية؛ يجب إبقاء التطبيق مفتوحاً.
- لم يتم بناء APK أو اختبار الخريطة على جهاز Android فعلي.


==============================
تحديث V2.6 — تتبع GPS في الخلفية
==============================
- أضيفت خدمة Android أمامية Foreground Service بنوع location لتواصل GPS أثناء انتقال التطبيق إلى الخلفية أو إغلاق الشاشة.
- يظهر إشعار دائم أثناء التتبع ويتضمن زر إيقاف. كما يبقى زر الإيقاف داخل صفحة الرحلات.
- تحفظ نقاط GPS المقبولة محلياً في SharedPreferences، ثم تتم مزامنتها مع سجل الرحلة عند عودة المستخدم إلى التطبيق.
- أضيفت أذونات Foreground Location وNotifications المطلوبة لإصدارات Android الحديثة.
- يبدأ التتبع من داخل التطبيق بعد منح إذن الموقع. لا يتطلب الإنترنت لتسجيل إحداثيات GPS؛ عرض خريطة الخلفية قد يحتاج الإنترنت.
- يجب اختبار الخدمة على جهاز فعلي، خصوصاً مع قيود البطارية وإدارة التطبيقات في بعض هواتف Android. لا يوجد APK مبني ضمن هذا الأرشيف.
- ملاحظة: إذا أوقف المستخدم التطبيق بالقوة من إعدادات Android أو أوقف صلاحية الموقع/خدمة الموقع، فقد يتوقف التتبع.


==============================
تحديث V2.7 — الملاحة والأماكن المفضّلة
==============================
- إضافة صفحة ملاحة مستقلة للأماكن المفضّلة.
- حفظ اسم المكان وإحداثياته ونطاق تنبيه الوصول محلياً تحت المفتاح driverProPlaces، دون تغيير driverProData أو السجلات القديمة.
- فتح توجيهات القيادة إلى الإحداثيات عبر تطبيق Google Maps إن كان مثبتاً، مع محاولة استخدام تطبيق خرائط آخر عند عدم توفره.
- إضافة تنبيه وصول أصلي من Android يعمل داخل خدمة GPS الأمامية، ويصدر إشعاراً عند دخول نطاق 50 إلى 2000 متر حول الوجهة.
- يمكن ضبط نطاق الوصول من 100 أو 250 أو 500 متر أو 1 كلم.
- يلزم تشغيل تتبع GPS من صفحة الرحلات حتى يتم رصد الاقتراب وإصدار تنبيه الوصول. إذا حفظت الوجهة قبل تشغيل GPS، يبقى الهدف محفوظاً ويبدأ رصده عند تشغيل التتبع لاحقاً.
- إدخال إحداثيات الوجهة يتم يدوياً في هذه النسخة؛ يمكن نسخ الإحداثيات من Google Maps. لا يوجد بحث عناوين/تحويل اسم المكان إلى إحداثيات داخل التطبيق بعد.
- الملاحة الفعلية والتوجيه الصوتي وإعادة حساب الطريق تتم داخل تطبيق الخرائط الخارجي، وليست محرك ملاحة مدمجاً داخل Driver Pro.
- يتطلب فتح الخرائط تطبيقاً متوافقاً، وقد يتطلب الإنترنت لتحميل الخرائط وحساب المسار.
- تنبيه الوصول يعتمد على دقة GPS وصلاحيات الموقع والإشعارات وإعدادات البطارية في الهاتف؛ لا تعتمد عليه وحده في القيادة أو السلامة.
- أضيفت قناة إشعارات منفصلة لتنبيه الوصول.
- تم رفع versionCode إلى 8 وversionName إلى 2.7.0.

التحقق والبناء:
- تم فحص صياغة JavaScript باستخدام Node.js.
- تم فحص سلامة أرشيف المشروع.
- تم تحديث GitHub Actions لاستخدام Gradle 8.9 وبناء assembleDebug عند تشغيل workflow يدوياً أو الدفع إلى main.
- لم يتم بناء APK في بيئة العمل الحالية لعدم توفر Android SDK وGradle محلياً، ولم يتم اختبار الملاحة أو تنبيه الوصول على هاتف حقيقي.

==============================
تحديث V2.7 — الملاحة والأماكن المفضّلة
==============================

المزايا:
- صفحة ملاحة جديدة لحفظ الأماكن المفضّلة محلياً على الهاتف.
- لكل مكان: الاسم، خط العرض، خط الطول، ونطاق تنبيه الوصول.
- نطاقات تنبيه متاحة: 100 متر، 250 متر، 500 متر، و1 كلم (ويحمي Android القيمة ضمن 50–2000 متر).
- زر استخدام آخر إحداثيات GPS مسجلة لتسهيل حفظ موقع حالي.
- فتح توجيهات القيادة إلى المكان عبر Google Maps إن كان مثبتاً، ثم تجربة تطبيق خرائط متوافق، ثم رابط خرائط عبر المتصفح.
- تنبيه وصول أصلي من Android عند دخول نطاق الوجهة. فحص نطاق الوصول يجري لكل قراءة موقع دقيقة، حتى إذا كانت المركبة متوقفة.
- يمكن اختيار تنبيه الوصول قبل تشغيل GPS؛ يبقى الهدف محفوظاً ويبدأ رصده عند تشغيل تتبع GPS لاحقاً.
- نسخ الأماكن المفضّلة والوجهة النشطة ضمن ملف النسخة الاحتياطية JSON واسترجاعها.
- تخزين الأماكن المفضّلة في localStorage تحت المفتاح driverProPlaces، والوجهة النشطة تحت driverProArrivalTarget، مع عدم تغيير مفتاح البيانات الأساسية driverProData.

طريقة الاستخدام:
1. افتح صفحة الملاحة.
2. أضف اسم المكان وإحداثياته. للحصول على الإحداثيات، افتح Google Maps واضغط مطولاً على الموقع ثم انسخ خط العرض والطول.
3. اختر نطاق تنبيه الوصول واحفظ المكان.
4. اضغط «ابدأ الملاحة» لفتح تطبيق الخرائط.
5. لتلقي إشعار الوصول، اضغط «تنبيه الوصول» ثم ابدأ تتبع GPS من صفحة الرحلات واسمح بإذن الموقع والإشعارات.
6. يمكنك إلغاء تنبيه الوصول من صفحة الملاحة.

حدود النسخة:
- إدخال الإحداثيات يدوي؛ لا يوجد تحويل عنوان مكتوب إلى إحداثيات (Geocoding) داخل التطبيق بعد.
- التوجيه خطوة بخطوة والصوت وإعادة حساب المسار تتم داخل تطبيق الخرائط الخارجي، وليست محرك ملاحة داخلياً.
- عرض الخرائط وحساب الطريق قد يتطلبان الإنترنت وتطبيق خرائط متوافقاً.
- تنبيه الوصول يحتاج استمرار خدمة GPS الأمامية. قد تتأثر الدقة بالمباني والأنفاق والطقس وإعدادات توفير البطارية.
- إذا رفض المستخدم إذن الإشعارات، قد لا يظهر إشعار الوصول في شريط Android؛ تحقق من أذونات إشعارات Driver Pro.
- لا تستخدم تنبيه الوصول كوسيلة سلامة وحيدة أو بديلاً عن الانتباه للطريق.

البناء والتحقق:
- versionCode: 8، versionName: 2.7.0.
- تم فحص صياغة JavaScript باستخدام Node.js.
- تم فحص بنية Manifest وسلامة أرشيف ZIP.
- تم تحديث GitHub Actions لاستخدام Gradle 8.9 لبناء app-debug.apk.
- لم يتم بناء APK في هذه البيئة لعدم توفر Android SDK وGradle محلياً، ولم يتم اختبار فتح الخرائط أو تنبيه الوصول على جهاز Android فعلي.

طريقة بناء APK عبر GitHub:
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات مجلد DriverPro إليه (المجلد الذي يحتوي app وbuild.gradle وsettings.gradle و.github).
2. افتح تبويب Actions في المستودع.
3. اختر Build Driver Pro APK ثم Run workflow.
4. انتظر انتهاء البناء. إذا نجح، افتح صفحة التشغيل الناجح (workflow run) ثم قسم Artifacts وحمّل Driver-Pro-V2.8-debug-apk.zip.
5. فك ضغط الملف لتحصل على app-debug.apk، ثم انقله إلى هاتف Android وثبّته بعد السماح بالتثبيت من هذا المصدر.

مهم:
- هذا APK من نوع debug للاختبار، وليس إصداراً نهائياً منشوراً على Google Play.
- لم يتم إنتاج APK داخل بيئة إعداد المشروع الحالية؛ يجب تنفيذ GitHub Actions أو البناء محلياً في Android Studio.
- لا تختبر GPS أثناء القيادة بنفسك؛ اختبره والهاتف ثابت أو مع شخص آخر يتولى القيادة.
- قبل تثبيت النسخة فوق نسخة سابقة، احتفظ بنسخة JSON احتياطية من بيانات Driver Pro.
- لا ترفع ملف google-services.json أو مفاتيح خاصة؛ هذا المشروع لا يحتاج Firebase.
